Extra Bangla fonts added in v3.0.1 (the original ten UI fonts are unchanged).

  Kalpurush        SIL OFL 1.0 — Md. Tanbin Islam Siyam, Avro Free Bangla Font Project.
                   Requested font. License is also in the font's name table.
  Siyam Rupali     GNU GPL — hinted by Md. Tanbin Islam Siyam, Avro Font Development Project.
                   Requested font. Full GPL text: GPL-2.0.txt.
  SolaimanLipi     SIL OFL 1.0 — a widely used Unicode Bangla face.
                   Substitute for Li Ador Noirrit. Re-checked in v3.0.2: the
                   font's own licence and Lipighor's EULA forbid distributing
                   it in any medium, so it cannot be bundled.
  Bornomala        SIL OFL 1.0 — © Codepotro, designer Jayed Ahsan Saad (v3.0.2).
                   Requested font, now bundled: Bornomala-Regular.woff2 v1.003,
                   unmodified, from https://webfonts.codepotro.com/bornomala/.
                   The name table states OFL 1.0. See OFL-Bornomala.txt.
                   It replaces Lohit Bengali, the v3.0.1 stand-in.
  AdorshoLipi      GNU GPL — designed by Partha Sarathi Pal.
                   Substitute for Noto Sans Bengali UI (Google no longer ships a
                   distinct UI cut separate from the Noto Sans Bengali already
                   bundled in this app). Full GPL text: GPL-2.0.txt.

Sources: OmicronLab Bangla font collection (Kalpurush, Siyam Rupali, SolaimanLipi,
AdorshoLipi) and Codepotro (Bornomala).
